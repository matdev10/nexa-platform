# Nexa Platform

# Platform Lifecycle

Versión: 1.0

Estado: Activo

---

# Objetivo

Este documento describe el ciclo de vida completo de una organización dentro de Nexa Platform.

Toda empresa que utilice Nexa seguirá este flujo.

---

# Etapa 1

## Descubrimiento

La organización conoce Nexa.

Puede llegar mediante:

- Página web
- Redes sociales
- Recomendación
- Publicidad

↓

Decide registrarse.

---

# Etapa 2

## Registro

El representante crea una cuenta.

Información mínima:

- Nombre
- Correo
- Contraseña

↓

Se verifica el correo electrónico.

---

# Etapa 3

## Creación de la organización

El usuario crea su primera organización.

Ejemplo

Nombre:

Millwords

Tipo:

Agencia

País:

Chile

Moneda:

CLP

Zona horaria:

America/Santiago

↓

Nexa crea automáticamente:

- Workspace
- Administrador
- Configuración inicial
- Dashboard

---

# Etapa 4

## Selección del plan

La organización selecciona un plan.

Ejemplo

Free

Starter

Business

Enterprise

Cada plan habilita distintos módulos.

---

# Etapa 5

## Activación de módulos

La organización decide qué módulos utilizar.

Ejemplo

✓ Dashboard

✓ Clientes

✓ Ventas

✓ Inventario

✓ Cotizaciones

✗ RRHH

✗ Contabilidad

---

# Etapa 6

## Personalización

La organización configura:

- Logo
- Colores
- Nombre comercial
- Idioma
- Moneda
- Formato de fecha

La plataforma comienza a representar la identidad visual del cliente.

---

# Etapa 7

## Invitación de usuarios

El administrador invita colaboradores.

Ejemplo

Juan

↓

Supervisor

Pedro

↓

Ventas

María

↓

Contabilidad

Cada usuario recibe únicamente los permisos necesarios.

---

# Etapa 8

## Operación

La organización utiliza Nexa diariamente.

Ejemplos

Registrar clientes

Crear cotizaciones

Gestionar ventas

Controlar inventario

Visualizar reportes

Administrar proyectos

---

# Etapa 9

## Crecimiento

Conforme la organización crece puede:

Agregar módulos.

Cambiar de plan.

Invitar más usuarios.

Crear nuevas sucursales.

Integrar APIs.

---

# Etapa 10

## Escalabilidad

Una misma cuenta puede administrar varias organizaciones.

Ejemplo

Matías

↓

Millwords

↓

Zeezton

↓

Constructora XYZ

↓

Cerebria

Cada organización mantiene completamente separados:

- Usuarios
- Clientes
- Ventas
- Reportes
- Configuración
- Inventario

---

# Principio fundamental

El usuario pertenece a Nexa.

Los datos pertenecen a la organización.

Nunca al revés.
